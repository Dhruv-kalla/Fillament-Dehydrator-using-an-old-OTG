BASIC PREVIEW
1) This is a simple filament dehydrator capable of reaching 100 degrees C, made using an old OTG and a free RTOS.
2) This is in V1, so it is missing a lot of features like a Wi-Fi dashboard and a fan.
3) This is capable of drying filaments like Nylon
4) I am not liable for anyone getting hurt due to this involving modifying the oven, for which one must work with live electricity and heat.
5) Only attempt this if you are comfortable with opening appliances

BASIC HOW TO:- 
1) First, get yourself an OTG, preferably an old one which uses dials to control its temp and time, as they have a setting which allows us to use the OTG forever.
2) Set the dial behind 0 mins (or wherever the setting for your oven is to make it run forever), and set the temp dial at 100
3) MAKE SURE IT IS NOT CONNECTED TO POWER; connect the SSR output to one of the heating coil pins and connect the other output pin to VCC (make sure the other end of the coil is connected to neutral somehow via the OTG or vice versa)
4) Make the pcb( i have provided schematic  and upload the code)
5) Connect the output pin to the SSR logic pin and give the SSR power and test if everything works while the oven is dismantled
6) Close the oven AFTER TURNING OFF THE POWER.
7) I have not given the method of connecting the LCD and SSR because it is supposed to be very basic, and I do not want people who do not know the basics to attempt this and possibly hurt themselves
